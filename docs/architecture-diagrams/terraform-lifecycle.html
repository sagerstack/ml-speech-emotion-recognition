Terraform Deployment Lifecycle

Core workflow for the EKS + ECR infrastructure in deployment/terraform
01
Init
Download providers/modules and set up the working directory before any plans or applies.
terraform init
Tip: Ensure AWS credentials/profile are loaded.
02
Plan
Create an execution plan against your state to review changes and costs before applying.
terraform plan -var-file=terraform.tfvars
Review: Validate EKS, VPC, IAM, and ECR diffs.
03
Apply
Provision or update AWS resources (VPC, EKS, IAM/OIDC, ECR) after confirming the plan.
terraform apply -var-file=terraform.tfvars
Outputs: Cluster name, ECR repos, GitHub OIDC role ARN.
04
Destroy
Tear down the stack. Run cleanup scripts first to remove load balancers and k8s resources.
./destroy.sh
Order: Delete k8s services → wait → terraform destroy.
